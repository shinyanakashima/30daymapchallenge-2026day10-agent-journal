# サンプルデータ：北海道の市町村と2025年国勢調査人口

制作モードの「サンプルデータを追加」で、この2つのファイルが記録の `data/` に入ります。出典とライセンスも自動で記入されます。

| ファイル | 内容 |
| --- | --- |
| `municipalities.geojson` | 北海道185市町村の境界（札幌市の10区は札幌市にまとめた）。属性：`code`、`name`、`subprefecture`（振興局）、`in_census` |
| `population_2025.csv` | 179市町村の人口。`pop2025`、`pop2020`（2025年の境域に組み替えた値）、`change`、`change_pct`、`area_km2`、`density_per_km2` |

`code`（5桁の全国地方公共団体コード）で結合できます。

## 出典

- 国土数値情報（行政区域データ）N03 2025年1月1日時点 北海道（国土交通省）、CC BY 4.0。<https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2025.html>
- 令和7年国勢調査 人口速報集計 第1表（総務省統計局、e-Stat）、政府標準利用規約（第2.0版）。<https://www.e-stat.go.jp/stat-search/files?toukei=00200521&tstat=000001230925>

どちらも加工しています（下記）。取得日：2026-11-10。元ファイルのSHA-256は `sources.json` にあります。

## 加工

- 境界：mapshaper 0.7.98 で市町村コードごとに統合し、頂点を1.5%に簡略化（隣接する境界は共有したまま）、座標を0.0001度に丸め、d3-geo 用にリングの向きをそろえた（外周が時計回り）。
- 人口：北海道の行のみ。札幌市は区の行を除き市の値を使用。合計が北海道の値（2025年 4,985,419人、2020年 5,224,614人）と一致することを確認した。

## 注意

- 北方領土の6村（01695〜01700）は境界ファイルにあり、`in_census` が false です。国勢調査の対象外のため、人口はありません。
- 簡略化した境界は描画用です。面積は CSV の `area_km2` を使ってください。
- 2025年国勢調査は速報値です。確定値とは異なる場合があります。
